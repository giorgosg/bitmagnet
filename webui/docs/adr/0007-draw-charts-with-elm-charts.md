# Draw charts with elm-charts, coloured through the theme tokens

Magnes draws its statistics charts with `terezka/elm-charts`. It gives every mark its colour as a `var(--token)` string through `CA.color`, and keeps the elements it uses, already themed, in one module of Magnes's own. The two shapes the operational pages need are a time-series line chart and a stacked bar chart. In a throwaway prototype that drew both four ways, elm-charts did it in about 40 lines, where drawing by hand took about 190 even with `terezka/intervals` choosing the ticks. elm-charts also brings hover tooltips and legends, which the hand-drawn version would have had to grow. The time-axis ticks come from the same `intervals` package, through `C.generate (C.times zone)`. Labels are formatted by Magnes, because elm-charts' default is US-style (`10/4`). Colouring through `var()` is a documented attribute and was verified to resolve inside SVG presentation attributes in Chromium and Firefox, in light and dark. The alternative, stylesheet rules on elm-charts' classes, also worked, but those class names are internal and undocumented. elm-charts' defaults are hard-coded light-theme greys (`#808BAB`, `#EFF2FA`), so no element may be used with its default colour. Each chart is a `figure` with a heading in its `figcaption`, an `svg` with `role="img"` and an `aria-label`, and a visually hidden table of the same numbers.

The price is bundle size, accepted for the simpler code. As deployed (`--optimize`, unminified), elm-charts added 245 KB raw and 40 KB gzipped to a 591 KB application, against 75 KB and 13 KB for the hand-drawn charts. `gampleman/elm-visualization` was not built: it is a toolkit of scales and shapes, so it would not have saved the code elm-charts saves. Libraries that render through a JavaScript runtime (Vega-Lite, Chart.js, ECharts web components) were rejected without a prototype, because they would be Magnes's first runtime JavaScript dependency for rendering. The prototype and the script that measures it (`e2e/prototype/measure-charts.mjs`) are on the `prototype/charts` branch (`56ce932`), and `.scratch/dashboard/issues/02-choose-how-to-draw-charts.md` records the full numbers.
